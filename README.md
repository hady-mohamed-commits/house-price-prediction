🏠 House Price Prediction — Machine Learning

An end-to-end Machine Learning regression project designed to predict house prices based on property characteristics and related features.

📌 Project Overview

This project focuses on building a Machine Learning model that can estimate house prices using different property-related features.

The project follows a complete Machine Learning workflow, including data cleaning, exploratory data analysis, missing-value analysis, duplicate and outlier analysis, feature preprocessing, model comparison, cross-validation, model evaluation, and deployment using Streamlit.

🎯 Objective

The main objective is to develop a regression model capable of predicting house prices accurately based on the available property features.

📊 Dataset

The dataset contains information about residential properties, including features related to:

* Property size
* Number of bedrooms
* Number of bathrooms
* Location-related information
* Property condition
* Other house characteristics

🤖 Machine Learning Model

Several Machine Learning approaches were considered and evaluated.

The final model used in the project is:

Gradient Boosting Regressor

The model was evaluated using 5-Fold Cross-Validation and standard regression metrics.

📈 Model Performance

Cross-Validation

* Mean R²: 0.810
* Standard Deviation: 0.009

Test Set

* MAE: 95,121
* RMSE: 179,103
* R²: 0.788

The R² score indicates that the model explains a substantial portion of the variation in house prices within the test data.
